# WFS361 Rubric - Simple Version

This version keeps the main requirements from the supplied WFS361 rubric while using simpler code.

## React Development & User Experience

- Reusable components: `MenuItem.tsx` and `Cart.tsx`
- State: `useState()` in `App.jsx`
- Dynamic rendering: menu comes from `data.js`
- Cart actions: add, remove, quantity and delete
- Navigation: Menu and Cart/Checkout views
- Clean structure: only a few easy-to-understand files

## Responsiveness

CSS includes desktop, tablet and mobile layouts.

## Important project requirements outside the code

The supplied rubric also awards marks for Figma design, GitHub commits and Netlify deployment. Those are completed separately from the React source code.
